## 什么是数学建模

**数学建模，就是用数学的方法理解和解决现实中的问题。**为了使读者可以更好地理解数学建模竞赛的三个步骤或分工，即建模、求解与论文，因此在解释什么是数学建模时也分为这三个板块。

### 模型建立

我们在面对一个现实问题时，可以抓住其中**最重要**的规律，再通过公式、方程、函数等数学语言描述这些规律，建立数学模型。例如，在高中数学中，我们就曾学习过：

- **抛体运动**：属于物理学中的经典力学建模。通过忽略空气阻力、将物体视为质点等合理假设，建立运动方程，分析和预测物体的运动轨迹。
- **线性规划**：属于运筹学中的数学优化领域。通过建立目标函数和约束条件，寻找满足条件的最优方案。
- **一元线性回归**：属于统计学中的回归分析方法，也广泛应用于机器学习和计量经济学。通过分析变量之间的关系，建立模型并进行预测。

这些看似不同的数学知识，其实都体现了数学建模的基本思想：**将现实问题抽象为数学问题，再利用数学方法进行分析和求解。**

由于我们的现实世界往往十分复杂，我们很难考虑所有因素。因此，在数学建模时，通常需要对问题作出合理的假设，忽略一些次要因素。例如，在刚刚提到的抛体运动中，我们通常会忽略空气阻力，并将物体视为质点；在研究天体运动时，我们可能将偏心率较小的椭圆轨道近似为圆形轨道，或将形状接近椭球体的天体简化为球体。

### 模型求解

在建立数学模型后，我们还需要对模型进行求解。仍然以刚刚提到的三个例子为例：

- **抛体运动**：将运动分解为水平方向的匀速直线运动和竖直方向的匀变速直线运动，利用运动学公式计算物体的位置、飞行时间、最大高度或水平射程。
- **线性规划**：通过绘制约束条件对应的可行域，利用图解法寻找目标函数的最大值或最小值，也就是高中数学中常见的“画可行域、平移直线”。
- **一元线性回归**：通常使用最小二乘法，根据已有的数据求出一条最能反映变量之间线性关系的直线，从而进行分析和预测。

但是，现实中的问题往往远比高中数学中的例题复杂。我们可能需要同时考虑成百上千个变量，面对大量的数据、复杂的约束条件，甚至是难以通过数学公式直接求解的问题。此时，传统的手工计算显然已经难以满足需求。因此，在实际的数学建模求解的过程中，我们通常需要使用利用Python、MATLAB等工具进行模型求解。这也正是为什么数学建模不仅需要数学知识，还需要一定的编程能力。

### 论文撰写

在完成模型的建立与求解后，我们还需要将整个研究过程整理成一篇数学建模论文。将我们的解决这个问题的这个过程在论文中进行体现，作为结果进行上交，参与评奖。

### 数学建模竞赛的流程

在了解什么是数学建模之后，其实也就不难理解什么是数学建模竞赛了。

一般来说，数学建模竞赛以团队形式参加，每支队伍通常由**3名队员**组成。完成组队后，可以官网自行报名，部分比赛在协会进行选拔和筛选后，由协会统一公费报名。

比赛正式开始后，参赛队伍需要从官方网站下载赛题，并根据自身的知识储备和兴趣选择其中一道题目进行研究。

与传统考试不同，**数学建模竞赛通常允许参赛者查阅书籍、文献、网络资料或[大语言模型](/todo)，也允许队伍内部自由讨论与分工协作**。在规定的比赛时间内（通常是三天三夜，没错这里把夜晚也算进了比赛时间，意味着可能会熬夜或通宵），队员们需要完成问题分析、模型建立、模型求解以及论文撰写等工作，最终提交一篇完整的数学建模论文。

提交论文后，接下来就是等待评审结果了。根据不同竞赛的奖项设置，参赛队伍可能获得国家级、省级或其他等级的奖项，也可能获得成功参赛奖，或未能获奖。

### 参赛节奏与学习安排

一般来说，对于本科生而言，**国赛**和**美赛**是最值得重视的两项数学建模竞赛。推荐以下的参赛节奏与学习安排：

- **大一上学期：以学习为主。** 这一阶段主要学习数学建模的基础知识。可以适当参加一些小型比赛，也可以不正式报名，只在比赛期间下载赛题进行练习，逐渐积累经验。
- **大一下学期：以中文竞赛为主。** 五一数学建模竞赛是我们学校比较重视的赛事，协会可能会在赛前组织简单培训，并统一安排报名。建议以此为目标，尝试完整经历一次从选题、建模、求解到论文撰写的比赛过程。
- **大二上学期：以国赛和英文竞赛为主。** 国赛是国内最具代表性的大学生数学建模竞赛，学校通常会参考五一数学建模竞赛等赛事的成绩进行选拔，并在暑假组织集训，统一安排参赛。
- **寒假**：美赛是国际上具有广泛影响力的英文数学建模竞赛，学校也可能组织选拔和报名。因此，可以提前参加一些小型英文数学建模竞赛，熟悉英文赛题与论文写作。

按照这样的节奏，大一上学期学习基础，大一下学期参加中文竞赛，大二上学期挑战国赛与英文竞赛。经历几次完整的比赛后，基本就算入门了。此后，无论是参加其他数学建模竞赛，还是进一步学习更复杂的模型与算法，都会更加得心应手。此时也算是基本上熟悉了数学建模竞赛的套路，可以尝试在各类比赛中“大杀四方”了。

::: tip 关于培训

一般来说，协会和学校都会组织一些[数学建模培训](/todo)。但作为一名大学生，你应当逐渐转变高中时期被动接受知识的学习方式，培养自主学习和主动探索的能力。

**培训只是辅助，真正的学习还得靠自己。** 这一点不仅适用于数学建模，也适用于整个大学甚至整个人生阶段的学习。
:::

## 一个很重要的误区：队伍应该如何分工？

::: warning 重要提醒

这是一个从初学数学建模到正式组队参赛，都很容易遇到的误区。因此，笔者认为，在介绍完数学建模和数学建模竞赛之后，有必要先把这个问题讲清楚。

:::

数学建模竞赛通常涉及模型建立、编程求解和论文撰写三个主要环节。巧合的是，一支参赛队伍通常也恰好有三名队员。因此，大家往往会将三个人分别称为建模手、编程手和论文手。这样的分工本身并没有问题，但有一个非常重要的前提：**分工不等于割裂。**

举个例子，我们不能简单粗暴地认为，找一个数学学院的同学负责建模、一个计算机学院的同学负责编程，再找一个文院的同学负责论文，就能组成一支优秀的数学建模队伍。问题不在于这些同学来自什么学院，而在于**三个人是否能够理解彼此的工作，并共同完成整个建模过程**。假如建模手建立了一个模型，但编程手和论文手完全不了解这个模型，那么谁来编写求解代码？谁来负责撰写模型原理、假设和求解过程？难道这些工作最后都要交给建模手一个人完成吗？

事实上，在大多数情况下，三名队员需要学习的基础知识是相通的，也都应当对数学建模的完整流程有所了解。所谓建模手、编程手和论文手，更多是根据各自的优势或偏好确定**主要负责的工作**，而不是将整个比赛机械地拆成三个互不干涉的部分。

::: info 什么是“好的队伍”？

笔者认为，一个真正的“好的队伍”，其中的任意一个人，单独拉出来都是可以一个人独立完整地完成一次数学建模竞赛，俗称“单刷”。

:::

当然，这并不是说数学学院的同学只能建模、计算机学院的同学只能编程，或者其他专业的同学不适合参加数学建模竞赛。恰恰相反，数学建模本身就是一项跨学科活动，专业背景并不能决定一个人在队伍中的角色。但如果非常不幸，你所学的专业与数学建模涉及的知识关联不大，那么你可能需要投入更多的时间和精力。

### 保研、考研、奖学金、评奖评优等

这不必多说，或不必在此处多说。更详细的，或许你可以[看看](/todo)。

### 锻炼科研思维

数学建模竞赛与研究生阶段的科研工作其实有很多相似之处，都需要经历查阅文献、分析问题、建立模型、求解验证以及撰写论文等过程。不同的是，研究生的一个课题往往需要持续数月甚至数年，而数学建模竞赛将这一过程压缩到了短短几天。

此外，研究生阶段的几乎所有涉及到数学或数值相关的科研课题都会涉及到数学模型与数据分析。因此，参加数学建模竞赛可以让你提前体验科研的基本流程，培养科研思维。

### 求职与工作中的实际价值

显然，对于数学建模、数据分析等直接相关的岗位，数学建模竞赛经历能够在一定程度上提高求职竞争力，这里不必赘述。

但即使是一些与数学建模并不直接相关、却需要经常与数据打交道的工作，数学建模中培养的数据分析能力和逻辑思维同样具有实际价值。毕竟，在实际工作中，许多决策都需要数据支持或理论依据，而不是仅凭主观经验作出判断。

### 培养定量分析思维

数学建模能够培养一种用数据和数学方法分析问题的思维。面对一个现实问题，不再仅凭直觉和经验作出判断，而是尝试将问题量化，通过建立模型、计算和比较不同方案，为最终决策提供依据。

::: details 真的要学数学建模吗？

曾几何时，笔者还在大学校园时，那时的笔者较为喜欢“劝学”，认为大好时光，没事学点编程什么的，有什么不好呢？但如今的笔者，或许已经变得有一些“功利”了。不管怎样，数学建模还是有一定学习门槛的。或许你的职业规划与数学建模关系不大，例如未来打算从事文学创作、艺术等领域的工作，那么学习数学建模或许对你的性价比可能并不是很高。

或许你也不知道自己是不是真的要学数学建模。不管怎样，**试试总没有错的。**要不，你试试？
